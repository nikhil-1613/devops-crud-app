🌐 Accessing the Application
{{- if .Values.ingress.enabled }}

  1. Start the Minikube tunnel (keep this running in a separate terminal):
     $ minikube tunnel

  2. Add this entry to your hosts file:
     127.0.0.1  {{ .Values.ingress.host }}

     Windows : C:\Windows\System32\drivers\etc\hosts
     Linux   : /etc/hosts

  3. Open in browser:
     Frontend  →  http://{{ .Values.ingress.host }}
     API       →  http://{{ .Values.ingress.host }}/api

{{- else }}

  Ingress is disabled. Use port-forwarding to access the app:

  $ kubectl port-forward svc/{{ $fullname }}-frontend 3000:{{ .Values.frontend.service.port }}
  $ kubectl port-forward svc/{{ $fullname }}-backend  5000:{{ .Values.backend.service.port }}

  Then open: http://localhost:3000

{{- end }}
